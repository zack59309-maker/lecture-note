# Enrich Note: 笔记知识自动补充

分析 Obsidian 里的课堂笔记，找出老师讲得浅、没讲清、或完全没涉及的知识点，用 LLM 自动补充完整内容。补充内容以 「📖 知识补充」区块追加到笔记末尾。

## 触发

- "补充笔记" — 处理 Obsidian 课程笔记中最新的一篇
- "补充复变函数的笔记" — 指定学科
- "补充 xxx.md 的笔记" — 指定文件

## 步骤

1. **找到目标笔记**
   - 用户指定学科 → 找对应目录下最新的笔记
   - 用户指定文件 → 直接用
   - 只说"补充笔记" → 所有课程笔记中最新的一篇

2. **运行补充脚本**
   ```bash
   cd ~/noteking-pro && ./enrich-note.sh <笔记路径>
   ```

3. **脚本自动做三件事：**
   - **分析** — LLM 识别笔记中讲得浅、缺失、可补充的知识点
   - **补充** — 对每个知识点生成 200-300 字补充内容（定义+要点+例子）
   - **写入** — 以「📖 知识补充」区块追加到笔记末尾，多次运行只替换该区块

4. **告知用户补充了哪些知识点**

## 注意

- 依赖 DeepSeek API，费用极低（补充一次几分钱）
- 重复运行同一笔记会替换旧补充内容，不会重复累积
- 补充内容用 `---` 分隔，用户可以手动编辑或删除
